Tanaka's Car Dealership

A simple API for Managing cars, Purchases, and Customer access.

Overview

This API simulates a modern car dealership backend. You can:

  • Browse available cars in the dealership inventory
  • Add, update, or remove cars
  • Create purchase records for customers
  • Protect endpoints using basic authentication

Key Endpoints

Cars

  • GET /cars – List all cars in the dealership inventory
  • POST /cars – Add a new car to the inventory
  • GET /cars/{car_id} – Get details of a specific car
  • PUT /cars/{car_id} – Update an existing car
  • DELETE /cars/{car_id} – Remove a car from the inventory

Purchases

  • GET /purchases – List all recorded purchases
  • POST /purchases – Create a new purchase
  • GET /purchases/{purchase_id} – Get details of a specific purchase

Authentication

  • GET /login-required – Test endpoint that requires login
