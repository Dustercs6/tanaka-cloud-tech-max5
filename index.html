Documentation & Usage Guide

Overview

This project is a cloud‑based e‑commerce API built using FastAPI. It supports product management, order processing, and authentication using HTTP Basic Auth. All protected endpoints require a valid username and password.

Authentication

The API uses HTTP Basic Authentication. When accessing protected endpoints, the browser will show a login popup.

Base URL

http://127.0.0.1:8000

Available Endpoints

Authentication

  • GET /login-required — Test endpoint requiring login

Products

  • GET /products — Get all products (requires login)
  • POST /products — Create a new product (requires login)
  • GET /products/{id} — Get a product by ID (requires login)
  • PUT /products/{id} — Update a product (requires login)
  • DELETE /products/{id} — Delete a product (requires login)

Orders

  • GET /orders — Get all orders (requires login)
  • POST /orders — Create a new order (requires login)
  • GET /orders/{id} — Get an order by ID (requires login)

Example: Create a Product

POST /products
Content-Type: application/json

{
  "id": 1,
  "name": "Cadillac CT5-V Blackwing",
  "price": 94990
}

Example: Create an Order

POST /orders
Content-Type: application/json

{
  "id": 1001,
  "items": [
    { "product_id": 1, "quantity": 2 }
  ],
  "total_price": 0
}
